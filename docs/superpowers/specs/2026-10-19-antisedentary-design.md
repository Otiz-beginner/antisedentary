# 防久坐小程式 設計文件

日期：2026-10-19
狀態：等使用者確認（已經過建造者審閱）

## 1. 為什麼要做這個

使用者是做 IC 設計（APR、讀論文）的人，常常一專心就在電腦前坐兩三個小時，等到卡住或身體痠痛才發現。久坐對心血管有害，就算平常有運動也抵銷不了；長時間盯著近距離螢幕也傷眼睛。

問題不是「不知道要休息」，而是**專心時完全感覺不到時間**。使用者也很清楚：被打斷時自己一定會不情願，如果給「再延後 5 分鐘」按鈕，自己**一定會一直按下去**。

所以這個程式要做到：

- **贏過當下的自己**：時間到就是要休息，不能討價還價
- **像水流一樣融入工作**：不突然跳出、不擋在畫面中間、不給壓迫感，讓人願意長期開著它

## 2. 目標、非目標、反目標

**目標**
- 偵測使用者是否持續坐在電腦前使用電腦
- 連續使用約 30 分鐘後，先給 3 分鐘收尾時間，再鎖住滑鼠和鍵盤 3 分鐘
- 讓使用者記下這段時間做了什麼，存在本機，之後可以在 dashboard 依日期查看
- 開會、簡報時有一個明確的「開會模式」可以暫停鎖定

**非目標（這一版不做）**
- 多台電腦之間同步資料（之後可能會做，見 §9）
- 休息時提示「可以做什麼運動」
- 帳號、雲端、手機 App
- 統計分析、目標設定、成就系統

**反目標（就算功能都有，出現這些也算失敗）**
- 有「延後 / 再 5 分鐘」按鈕，或任何讓人在休息時間到時繞過鎖定的日常捷徑（開會模式除外，見 §4.5）
- 提醒突然跳到畫面正中間，或用醒目的倒數數字製造壓迫感
- 卡片在使用者打字、點其他視窗時自己消失
- 程式出錯時把使用者永遠鎖在外面
- 太煩，讓使用者最後選擇把它關掉

## 3. 一輪的時間軸

```
0:00 ─────────────── 29:00 ──────────── 32:00 ──────── 35:00
     正常工作（偵測中）   提醒卡出現，水慢慢退   鎖定休息，水慢慢漲   解鎖，回到 0:00
```

- **29:00**：右下角出現提醒卡，水是滿的
- **29:00–32:00**：水位一路退到 0，這就是倒數，不顯示任何數字
- **32:00**：水位退到 0 的那一刻自動鎖定
- **鎖定 3 分鐘**：水從杯底慢慢漲滿，滿了就解鎖
- **解鎖後**：計時從 0 重新開始

數字（29 / 3 / 3 分鐘、閒置判斷的 90 秒 / 3 分鐘）放在設定檔裡，方便之後調整。這一版**不需要**做設定介面。

## 4. 行為規則

### 4.1 判斷「在不在電腦前」
- 只要 **90 秒內**有任何滑鼠移動、點擊、滾輪或按鍵，就算使用者在電腦前，繼續計時
- 如果**連續 3 分鐘**完全沒有輸入，就當作使用者已經離開休息過了，**計時歸零**。例如等 APR 跑完時，使用者會自己站起來走走
- 90 秒到 3 分鐘之間沒有輸入，例如轉頭跟人講話：計時照算，不歸零
- 電腦睡眠、螢幕鎖定（Win+L）、登出的時間，都算離開。回來時如果已經超過 3 分鐘，就歸零
- 以下是我的決定（建造者審閱時提出，使用者沒有特別指定）：
  - **不到 3 分鐘的 Win+L 或睡眠**：跟 90 秒到 3 分鐘的沒有輸入一樣處理，時間照算，不暫停
  - **提醒卡出現時也一樣適用閒置歸零**：例如 28:30 起身離開，到 31:30 滿 3 分鐘沒輸入，提醒卡就收起來、計時歸零。這一段存成「閒置歸零」，輸入框裡如果已經寫了字，也要存起來。這樣使用者回來時，不會撞上一個毫無意義的鎖定
  - **鎖定的 3 分鐘本身就是休息**：不管這段期間有沒有被擋下的按鍵，解鎖後一律從 0 開始

### 4.2 提醒卡（29:00–32:00）
- 位置：主螢幕右下角。是一張小卡片，**不搶焦點**，不擋住使用者正在打字的視窗
- 一直在最上層，直到鎖定才消失。使用者點其他視窗、捲動畫面，卡片都不會消失
- 內容：
  - 標題「快到休息時間了」
  - 一個多行輸入框，提示文字是「這段時間做了什麼？（可以不寫）」
  - 一個按鈕「開始休息」
- 寫不寫都可以。沒寫的話，時間到照樣鎖定
- 按「開始休息」：馬上進入鎖定（§4.3），不用等水退完
- 沒有延後、關閉或最小化按鈕
- 鎖定的那一刻，輸入框裡的文字（就算是寫到一半）會自動存成這一段的紀錄

### 4.3 鎖定休息（3 分鐘）
- **所有螢幕**都變暗加模糊（深色 `#2E3A55` 約 55% 不透明 + 模糊），還隱約看得到背後的工作畫面
- 主螢幕右下角放一張小卡片，上面寫「休息一下」和 `m:ss` 倒數，水從杯底慢慢漲滿
- 不放「可以做什麼」的提示
- **擋住滑鼠和鍵盤**：一般操作都沒有作用，包括點擊、打字、Alt+Tab、Win 鍵
  - Ctrl+Alt+Del 擋不掉，這是預期的：這個鎖是用來擋「正常的自己」，不是防駭客
- 3 分鐘到就自動解鎖，卡片淡出
- **全螢幕程式**（這是我的決定）：遮罩用最高的置頂層級，例如 Electron 的 `screen-saver` 層級，盡量蓋過全螢幕影片或程式。如果實測發現有蓋不過的情況，鎖定照樣進行，同時用 Windows 通知顯示「休息一下」，避免使用者被鎖住卻看不到任何提示
- **安全保險**：
  - 不論發生什麼事，鎖定最長 3 分鐘
  - 程式當掉或被結束時，滑鼠鍵盤必須立刻恢復。所以輸入攔截要綁在程式的行程上，不能留下系統層級的設定

### 4.4 主動休息
- 系統匣選單裡有「現在休息」，選了就直接進入鎖定（§4.3）
- 這樣主動休息也沒辦法作弊：按了就真的會鎖住
- 主動休息也會存成一段紀錄，跟提早休息一樣標記

### 4.5 開會模式（使用者明確要求的唯一逃生門）
- 兩種方式可以開啟：
  - 系統匣選單「開會模式」
  - 全域快捷鍵（預設 `Ctrl+Alt+Shift+M`）
- **在任何狀態都可以開**：正常工作中、提醒卡出現時、**鎖定中**都可以。鎖定中按快捷鍵會立刻解鎖
  - 原因：開會或簡報時剛好遇到鎖定，不能讓使用者在別人面前卡住 3 分鐘
- 開啟後，**不會跳出任何提醒或鎖定**，直到使用者自己關掉。不會自動過期
- 開會模式中，系統匣圖示要明顯不一樣（例如改成紫色），提醒使用者還在開會模式
- 關掉時，計時從 0 重新開始
  - 這是我的決定：開會時多半有在說話、移動，不像專心寫 code 那樣完全不動
- 開會模式的開始和結束時間要記錄下來，dashboard 上可以看到（見 §6）
- 從提醒卡狀態進入開會模式時，輸入框裡已經寫的字一樣要存起來

### 4.6 開機與系統匣
- 安裝後預設**開機自動啟動**，不用管理員權限
- 系統匣圖示的選單：
  - 打開紀錄（dashboard）
  - 現在休息
  - 開會模式（開／關）
  - 結束程式
- 「結束程式」不需要特別防呆。真的想關，使用者本來就可以從工作管理員關掉，防呆只會讓它變煩

## 5. 資料

- 只存在本機：`%APPDATA%\antisedentary\`
- 程式本身放在 `D:\antisedentary`，跟資料分開。重裝或更新程式不會弄丟紀錄
- 使用 SQLite 資料庫，一個檔案
- 每一段工作存一筆，至少要有：
  - 開始時間、結束時間（含日期，用本地時區）
  - 這段怎麼結束的：時間到 / 自己按開始休息 / 系統匣「現在休息」 / 閒置自動歸零 / 進入開會模式 / 程式結束
  - 紀錄文字（可以是空的）
  - 電腦名稱（現在只有一台，先存起來，方便之後做同步）
- 開會模式另外存一筆：開始時間、結束時間
- 因為閒置 3 分鐘而歸零的那段也要存，但沒有紀錄文字，dashboard 上可以跟其他段區分開來
- 將來要做同步時，只要把這個資料夾換成雲端硬碟資料夾，或改成一台電腦一個檔案。這一版不用做

## 6. 紀錄 Dashboard

從系統匣「打開紀錄」開啟，是一個獨立視窗。參考草圖 `.superpowers/brainstorm/mockups/dashboard-v1.html`，使用者已經確認「大概這樣」。

由上到下：
1. **總覽四格**：
   - 總工作時間（小時）
   - 工作段數
   - 平均每段多久（分鐘）
   - 有寫紀錄的段數
2. **日曆熱度圖**：
   - 上方三個數字：有工作的天數、目前連續天數、最長連續天數
   - 下方一格代表一天，顏色深淺代表那天的工作段數。由淺到深：`#E6E9F3`、`#D3D5FF`、`#92C7FF`、`#7B9DC8`、`#4E6FA0`
   - 預設顯示最近，可以往前捲
   - 點一格就在下方顯示那一天
3. **某一天的細節**：
   - 標題「10 月 19 日（一）」，旁邊寫「N 段，共 X 小時 Y 分」
   - 一條 8:00–24:00 的時間軸，標出每一段的位置。開會模式也標上去，用另一種顏色
   - 逐段列出：
     - 時間範圍、長度、紀錄文字
     - 沒寫的段顯示「沒有寫紀錄」
     - 提早休息的段加「提早休息」小標籤
   - 開啟時預設顯示今天

「一段」的定義：從計時開始，到進入鎖定、閒置歸零或進入開會模式為止。

**很短的段**（這是我的決定）：資料庫裡每一段都要存。但「閒置歸零」而且不到 5 分鐘、也沒有紀錄文字的段，在 dashboard 上不顯示，也不算進總覽數字。避免等 APR 時偶爾碰一下滑鼠，就產生一堆碎片段。

## 7. 視覺

參考草圖 `.superpowers/brainstorm/mockups/screens-v5.html`（提醒卡、鎖定卡）。使用者已經逐項確認。

- **色票**（使用者提供）：
  - `#7B9DC8` 霧藍：按鈕
  - `#BFC9DF` 灰藍：邊框
  - `#92C7FF` 水藍：水
  - `#D3D5FF` 淡薰衣草：卡片底色漸層
  - `#D2BAFF` 淡紫：水面亮線、焦點外框
  - 深色字用 `#2E3A55`
- **字型**：
  - 標題、「休息一下」、倒數數字用粉圓體（Huninn）
  - 內文用 Noto Sans TC，沒有時退回微軟正黑體
  - 字型要**打包進程式**，不要依賴網路
- **卡片**：
  - 不對稱圓角（20/20/20/6px），像被水沖圓的小石頭
  - 從右下角輕輕浮上來，這是唯一的進場動畫
- **水杯**：整張卡片就是一個水杯
  - 水在文字和輸入框**後面**，水面是緩慢移動的雙層波浪
  - 提醒時水位從滿退到 0，休息時從 0 漲到滿
  - **不要**水滴落下的動畫（試過，使用者拿掉了）
- **不顯示數字的地方**：提醒卡不顯示倒數秒數。只有鎖定卡顯示 `m:ss`
- 系統設定開啟「減少動態效果」時，波浪停住，只改變水位

## 8. 技術方向（我的決定，使用者沒有指定）

- **Electron**：草圖本身就是 HTML/CSS，可以幾乎直接沿用。透明、永遠在最上層、不搶焦點的視窗，Electron 都能做到。dashboard 也是網頁
- **偵測閒置**：用 Electron 的 `powerMonitor.getSystemIdleTime()`，加上睡眠、鎖定畫面的事件。不需要安裝鍵盤側錄式的 hook
- **鎖住輸入**：要在鎖定期間吞掉全系統的滑鼠鍵盤事件，並保留開會模式快捷鍵。這需要原生的 low-level keyboard/mouse hook，可以用 Node 原生模組，或一個小的 C# 輔助程式
  - 不能用需要管理員權限的 `BlockInput`
  - 不管用哪一種，都必須符合 §4.3 的安全保險：行程一結束，hook 就跟著消失
- **儲存**：SQLite（例如 better-sqlite3）
- **打包**：打包成 Windows 可執行檔，放在 `D:\antisedentary`，開機啟動用目前使用者的啟動項，不需要管理員權限
- 使用者電腦上已經有 Node.js 24 LTS 和 Python 3.14
- **執行環境**：
  - 裝在使用者自己管理的 Windows 11 電腦上，使用者本人就坐在這台電腦前，沒有公司 IT 限制
  - 不需要程式碼簽章或 IT 白名單
  - 偵測和鎖定都在這台電腦本機進行。就算 APR 是透過遠端視窗連到別台機器，輸入也是從這台電腦送出去的
  - 防毒軟體如果把鍵盤 hook 誤判成可疑程式，使用者可以自己加例外
  - 已知的限制：當焦點在「以系統管理員身分執行」的視窗時，一般權限的 hook 可能擋不住那個視窗的輸入。這一版接受這個限制，不要求整支程式用管理員權限執行

## 9. 留給建造者決定的
- 專案結構、模組怎麼切、測試怎麼做。測試盡量讓計時邏輯可以用假時鐘測，不用真的等 30 分鐘
- 鎖住輸入要用哪一種原生方式（§8 的兩個選項，或其他符合 §4.3 的做法）
- 系統匣圖示的樣子
- dashboard 熱度圖「深淺」的分級門檻
- 主螢幕以外的螢幕上，變暗加模糊的實作細節
- 要不要做一個「開發用的加速模式」，例如 1 分鐘當 1 小時，方便測試

## 10. 之後可能會做（這一版不做）

- 設定介面（調整時間長度、快捷鍵）
