# 防久坐小程式（Antisedentary）

連續使用電腦 29 分鐘後，右下角會浮出一張「水杯」提醒卡。給你 3 分鐘收尾，也可以記一下這段時間做了什麼。時間到就鎖住滑鼠鍵盤 3 分鐘，讓你起來動一動、看看遠方。

設計文件：[docs/superpowers/specs/2026-10-19-antisedentary-design.md](docs/superpowers/specs/2026-10-19-antisedentary-design.md)

## 開始用

需要 Windows 11 和 Node.js 24。

```bash
npm install
```

```bash
npm start
```

打包成可以直接執行的程式：

```bash
npm run dist
```

打包完的程式在 `dist\win-unpacked\Antisedentary.exe`。執行一次後，之後每次登入 Windows 都會自動啟動。

重新打包前，要先讓正在跑的程式存好檔再結束。用工作管理員強制結束的話，正在計的那一段會遺失：

```powershell
& "D:\antisedentary\dist\win-unpacked\Antisedentary.exe" --quit
```

## 東西放在哪裡

| 內容 | 位置 |
| --- | --- |
| 程式 | `D:\antisedentary\dist\win-unpacked\` |
| 紀錄資料庫 | `%APPDATA%\antisedentary\antisedentary.db` |

重裝或更新程式都不會動到紀錄。

## 怎麼操作

- **系統匣（右下角的人坐著的小圖示）**：
  - 打開紀錄
  - 現在休息
  - Lock-in 專注模式
  - 結束程式
- **Lock-in 專注模式**：按快捷鍵（預設 `Ctrl+Alt+Shift+M`）、紀錄頁右側的「Lock-in 專注模式」按鈕或系統匣開啟，鎖定中也可以按。專注中沒有工作時長限制，不提醒也不鎖定；按鈕和系統匣圖示會變成紫色。結束時右下角會請你寫下這段專注做了什麼，水在收尾時間內退光就進入休息（收尾時再按一次可以回到專注）。
- **緊急逃出**：鎖定休息時遇到急事，按快捷鍵（預設 `Ctrl+Alt+Shift+E`）立刻解鎖，結束這次休息，之後照常計時。
- **使用教學**：第一次開啟程式會自動跳出；之後可以從「紀錄」頁左側欄的「使用教學」再打開。
- **離開 3 分鐘**：完全沒有操作滿 3 分鐘會暫停計時。回來時右下角會問「剛剛有站起來嗎？」；離開超過 30 分鐘就不問，直接算休息。
- **提早休息快捷鍵**：按 `Ctrl+Alt+Shift+B`（可在設定裡換），右下角浮出跟提醒卡一樣的卡片；離鎖定還超過收尾時間時水是滿的。按卡片右上角的 × 或再按一次快捷鍵就收起。
- **補寫紀錄**：紀錄頁當天清單每一段旁邊都有「補寫／修改」，可以事後補上這段做了什麼。點時間軸上的區塊會跳到那一段。
- **刪除紀錄**：每一段旁邊的「刪除」會先問「確定刪除？」，按「刪除」才真的刪掉。每天第一次開程式時會自動備份一份資料庫到 `%APPDATA%\antisedentary\backups\`（保留 14 天），刪錯還找得回來。
- **休息畫面**：設定的「休息畫面」可以選背景（模糊目前畫面／內建桌布）和中央的大標語（TAKE A BREAK／摸魚中…／不顯示／自己輸入）。模糊是鎖定前先拍下螢幕再模糊，遠端桌面也看得到；拍不到時（例如遠端桌面視窗縮到最小）會改用內建桌布。
- **從紀錄頁提早休息**：「紀錄」頁右側的「提早休息」可以寫下這段做了什麼，按「開始休息」就馬上鎖定休息，紀錄會標成「提早休息」。
- **設定**：「紀錄」頁左側欄的「設定」會在畫面中央打開設定面板，分成「快捷鍵」「時間設定」「休息畫面」「其他」四群：Lock-in、緊急逃出、提早休息三組快捷鍵，工作時長、休息時長、手機上限等時間，以及開機自動啟動開關。每項旁邊的「?」有詳細說明，按「儲存設定」就馬上生效。

## 開發

```bash
npm test
```

加速模式會把所有時間除以倍數，例如 60 倍時一輪只要 35 秒：

```powershell
$env:ANTISEDENTARY_SPEED=60; npm start
```

鎖住滑鼠鍵盤的是 `native/lockhelper.cs`，用 Windows 內建的 `csc.exe` 編譯：

```bash
npm run build:helper
```

它最多只會鎖 `--max-seconds` 秒，主程式結束時也會跟著結束，所以不會把你永遠鎖在外面。
